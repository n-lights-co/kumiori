draw.io の図のページの選び方

この見本は、3 ページの draw.io の図のファイル diagrams.drawio から、画像の参照の # の後ろで描くページを選びます。 ファイルのページは、1 ページ目「全体図」(id overview)、2 ページ目「組版の流れ」(id flow)、 3 ページ目「凡例」(id legend。中身を圧縮した形) です。それぞれの図の下の字で、どのページを描いたかが分かります。

1. 何も付けない: 最初のページ

2. #page=N: N ページ目 (1 から数える)

PDF の #page=N と同じく 1 から数えます。draw.io の画面の URL の page は 0 から数えるので、1 ずれます。

3. #page-id=ID: id で選ぶ

ファイルの <diagram id="…"> の値です。ページの名前を変えても参照が変わりません。このページは中身を圧縮した形で入っています。

4. #名前: ページの名前で選ぶ

draw.io の画面の下のタブに出る名前です。日本語・空白は % の形 (%E5%87%A1%E4%BE%8B など) で書いても同じです。

5. 無いページ: 最初のページを描いて警告する

組むと「draw.io の図に 9 ページ目がありません (3 ページ。最初のページを描きます)」の警告が出ます。
