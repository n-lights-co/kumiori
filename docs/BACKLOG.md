# 未対応・既知の制限 (バックログ)

Kumiori にまだ無い機能・既知の制限の一覧。着手したら「状態」を更新し、完了したら「状態」を「完了」にする (行は履歴として残す)。
出典: 公開されている XSL-FO のサンプルでの変換レポート、各機能の実装時メモ。仕様の項目ごとの対応・未対応は対応仕様説明書 (`docs/conformance/`) にある。

**いまも未対応・一部のもの (要約)**: PDF/X-3 (ISO 15930-6)・PDF/X-1a:2003 (ISO 15930-4) の本文による確認 (O-03・O-07。PDF/X-1a:2001 と PDF/X-4 は本文に合わせた)。CGM の GDP・POLYSYMBOL は、登録された中身が無いので描画しない (I-09)。EPS (PostScript) の CCITTFaxDecode フィルタは持たない (I-03)。XSL-FO のアンテナハウスのフロートの拡張 (`axf:float-x` など。ページ・段を基準に置く回り込み) は未着手 (I-11)。組み直しの読み込みとカスケードの差分 (P-02)・pdf-lib のフォントの埋め込みの置き換え (P-04。画像の埋め込みは 0.8.0 で自前にした) は 0.8.0 以降。ほかに、状態が「ほぼ完了」「一部完了」の行と、メモに「残り」のある行にも残りがある。詳しくは各行のメモ。
優先度: **高** = サンプル・実文書で頻出 / **中** = 時々出る / **低** = まれ・回避策あり。
