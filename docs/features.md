# できること

Kumiori の機能を、分類ごとにまとめます。プロパティごとの対応状況と、仕様の定義・Kumiori での扱いは、対応仕様説明書 ([`docs/conformance/`](conformance/README.md)) にあります。
まだ無い機能・既知の制限は [`docs/BACKLOG.md`](BACKLOG.md) にあります。

## 入力

| 種類 | 中身 |
| --- | --- |
| HTML+CSS | 自前の CSS カスケードで読む (ブラウザー不要) |
| XSL-FO | XSL-FO 1.1。アンテナハウスの拡張 `axf:*` のうち、よく使われるものを中心に一部に対応 |
| EPUB | 画面 (ブラウザー) で開ける ([`docs/app.md`](app.md)) |
| 画像 | PNG・JPEG・GIF・BMP・TIFF・WebP・SVG・WMF・EMF・EPS (PostScript)・CGM・PDF (ページを図として貼る。PDF の出力だけが描画し、画面・SVG・PNG はプレースホルダー。[`docs/library.md`](library.md) の「PDF の画像」) |
| 図 | draw.io の図 (`.drawio`・`.dio`。[`docs/drawio.md`](drawio.md)) |

画像の形式は、プラグインで追加できます ([`docs/library.md`](library.md) の「プラグイン」)。

## 日本語組版

- 縦書き・横書き
- ルビ、縦中横、圏点
- 禁則、ぶら下げ・追い出し、約物の詰め、和欧間のアキ
- 割注

割注は、Kumiori の拡張の CSS の `-kumiori-warichu`・XSL-FO の `kumiori:warichu` で書きます。標準にも、他の組版ソフトの拡張にも書き方が無いためです。
説明は、対応仕様説明書の HTML と CSS 編の 9.2 節、XSL-FO 1.1 編の 4.6 節にあります。

## 多言語

| 文字・言語 | 組み方 |
| --- | --- |
| アラビア語・ヘブライ語などの右から左の文字 | Unicode の双方向アルゴリズム (UAX #9) で並べ替え、アラビア文字は前後につながる字形にする。CSS の `direction: rtl`、XSL-FO の `writing-mode="rl-tb"` |
| タイ語 | 語の境界を、実行環境の `Intl.Segmenter` の辞書で決めて折り返す |
| デーヴァナーガリー (ヒンディー語など) | 結合子音などをフォントで整形する |
| ほかのインド系の文字 | ベンガル・グルムキー・グジャラート・オリヤー・タミル・テルグ・カンナダ・マラヤーラム・シンハラ |
| 東南アジア・チベットの文字 | ラオ語・クメール語・ビルマ語 (ミャンマー文字)・チベット語 |
| モンゴル文字 | 横書きと縦書き |
| 韓国語・中国語 | ハングル、簡体字・繁体字 |
| ベトナム語・ギリシャ文字・キリル文字 | 既定の欧文のフォントで組める |
| 欧文のハイフネーション | 英語・ラテン語・ロシア語・ウクライナ語・現代ギリシャ語・ドイツ語・フランス語・スペイン語・イタリア語・ポルトガル語・オランダ語・ポーランド語・デンマーク語・スウェーデン語・ノルウェー語・フィンランド語・ハンガリー語・スロバキア語・スロベニア語・クロアチア語・セルビア語・ブルガリア語・エストニア語・リトアニア語・アイルランド語・ウェールズ語・カタルーニャ語・ガリシア語・バスク語・アイスランド語・トルコ語 (チェコ語などは、規則のライセンスが合わないので分綴しない) |
| 欧文と和文の混在 | 和欧間のアキを入れて組む |

フォントについて:

- アラビア文字・タイ文字・デーヴァナーガリー・ハングル・簡体字と繁体字・カラーの絵文字などのフォントは、既定のフォントには無いので、`--font` や `fonts` で渡します。
- 中国語の漢字の多くは既定の和文のフォント (Noto Serif JP・Noto Sans JP) にもありますが、字形は日本の形で、簡体字だけの文字の多くは入っていません。中国語の文には、中国語のフォントを渡してください。
- 単色の絵文字は、既定の Noto Emoji で組めます。
- カラーの絵文字のフォントは、色の付いたまま組めます。
- ヘブライ文字・ギリシャ文字・キリル文字・ベトナム語の文字は、既定の欧文のフォントで組めます。

言語と文字ごとの、要るフォント・折り返し・縦書き・制限の一覧は、対応仕様説明書の「対応している言語と文字」の節 (XSL-FO 1.1 編の 5.6 節、HTML と CSS 編の 5.8 節) にあります。
同じ節に、文字ごとの組版のサンプル (世界人権宣言の第 1 条を、それぞれの文字のフォントで組んだもの) があります。可変フォントと絵文字のサンプルは、HTML と CSS 編の 5.6 節・5.7 節にあります。

## ページ

- ページマスター、柱・ノンブル
- 脚注、段組、回り込み
- 表 (行・ページをまたぐ分割、ヘッダーの繰り返し、列の幅の自動決定)
- ページ番号の参照

## 出力

| 出力 | 中身 |
| --- | --- |
| Canvas | 画面のプレビュー |
| PDF | フォントのサブセット埋め込み、しおり、リンク、注釈、フォーム、トンボ |
| タグ付き PDF・PDF/UA-1 | 見出し・段落・リスト・図・リンク・表・脚注の構造と読む順、図の代替テキスト、言語 (`--tagged`・`--pdfua`) |
| PDF/X | PDF/X-1a・PDF/X-3・PDF/X-4 の印と、RGB の色・画像の CMYK への変換 (`--pdfx`) |
| PDF/A | 長期保存用の PDF/A-2b・PDF/A-3b の印 (`--pdfa`) |
| SVG・PNG | ページごとに書き出す |
| JSON | 論理ツリーを JSON で保存できる (画面) |

PDF/X-1a と PDF/X-4 は、規格 (ISO 15930-1・ISO 15930-7) の本文を読んで作り、その要件に適合することを検証しています。書き出した PDF も、その要件で調べます。入稿の前には、プリフライトで検証してください。
PDF/A は、規格の本文ではまだ検証していないので、規格への適合は保証しません。保存の前に、検査のツールで検証してください。
検証した規格の本文と、検査の中身は、[`docs/library.md`](library.md) の「PDF/X と PDF/A」にあります。
