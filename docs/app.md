# 画面 (ブラウザ) の使い方

ブラウザで文書を開き、組んだページを見て、PDF を保存する画面です。
GitHub Pages に置いた画面 (<https://n-lights-co.github.io/kumiori/>) を開くか、`npm run build` の `dist/` を静的なウェブサーバーに置いて使います。

## 開く

- 「開く」で、HTML・XSL-FO・EPUB を、使う CSS・画像・書体と一緒に選びます (複数選べます)。
- 「フォルダを開く」でフォルダごと選ぶか、ファイルやフォルダを画面にドラッグ&ドロップしても開けます。
- フォルダに文書が複数あるときは、index.html (無ければ浅い場所の文書) を開きます。

## 保存する

「PDF を保存」で PDF を書き出します。「論理ツリーを JSON で保存」で、読み込んだ文書の論理ツリー (組む前の、文書の構造と書式) を JSON にして書き出します (<文書の名前>.json)。左には、ページの縮小画像と警告 (たためる) が並びます。

上の「API の説明書」で、ライブラリの関数・型・選択肢の一覧 ([API の説明書](https://n-lights-co.github.io/kumiori/api/)) を新しいタブで開きます。狭い画面では、「設定」の「そのほか」にあります。

## 設定

右の「設定」には、次のものがあります。

| 設定 | 中身 | コマンドの対応 |
| --- | --- | --- |
| 既定のスタイル | HTML の既定のスタイル | `--style` |
| 既定の用紙 | `@page` で `size` を指定していない HTML の用紙。A4・A5・B5・JIS-B5・letter と自由入力 | `--page-size` |
| CSS の解釈 | 自前のカスケード (既定) か、比べるためのブラウザの iframe | |
| 仕様どおりの既定値で組む | XSL-FO の既定値の流儀 | `--compat` |
| トンボ | トンボと塗り足し 3mm を付ける | `--print` |
| ガイドの表示 | 仕上がり・塗り足しのガイド線を、画面のページに描く (既定はオン。トンボを付けたとき。PDF には入らない) | (API の `renderPage` などの `guides`) |
| タグ付き PDF | 文書の構造・読む順・図の代わりの文・言語を PDF に入れる (既定はオン。見た目は変わらない)。オフにするとタグを付けない | `--tagged`・`--no-tagged` |
| 書体の読み込み | 手元の PC にある書体 (TTF・OTF・TTC。MS 明朝・MS ゴシックなど) を読み込んで使う。PC の外へは送らない | `--font` |
| draw.io の図 | 読む・読まない、図形ライブラリ ([`docs/drawio.md`](drawio.md)) | `--no-drawio` など |

## 警告

警告は、左の欄に 1 件ずつ並びます。

- 同じ文はまとめます。4 件以上は畳んで件数だけを見せ、開けば読めます。件数は上の帯にも出ます。
- 各行には、重さの印 (✖ 出力が欠けた・⚠ 警告・ℹ 知らせ) と、診断の名前 ([`docs/diagnostics.md`](diagnostics.md)) を付けます。分かれば、要素・行・ページも添えます。
- ページの分かる行を押すと、そのページへ移ります。
- HTML の警告には、行は出ません。画面は HTML をブラウザの HTML の読み込み (`DOMParser`) で読み、その読み込みが字の位置を持たないためです (CSS の解釈が「Kumiori」でも「ブラウザ (比較用)」でも同じ)。XSL-FO の警告には行が出ます。行が要るときは、コマンドか API で組みます。

出るのは、コマンド・API の警告と同じものです。

- 組版の警告
- 未対応の CSS・XSL-FO と、知らない CSS のプロパティ
- 安全のため PDF に動作を書かなかったリンク
- 128 段より深い入れ子・多すぎる `@import`
- EPUB の上限を超えて飛ばした項目
- 取らなかった画像
- 書体の知らせ (取得できなかった書体など)

## 文書を外へ送らない

組版はすべてブラウザの中で行い、文書や書体を外へ送りません。
外から取るのは、既定の書体と、文書が `http(s):` で参照する画像と、「設定」で許したときの draw.io の図形ライブラリだけです。
`npm run build` の `dist/` を静的なウェブサーバーに置いても動きます。オフラインで使うときの書体の置き方は [`docs/fonts.md`](fonts.md) にあります。
