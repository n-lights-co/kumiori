# 用語の一覧 (日本語の文書・文言の言葉の選び方)

開発の決まり (`CLAUDE.md` の「言葉」) の用語集です。利用者が読むもの (README・`docs/`・変更履歴・`samples/`・警告とエラーのメッセージ・公開の API の型定義のコメント・画面の文言・対応仕様説明書) は、この一覧の語で書きます。
内部のモジュールのコメントと `design/` は、触った所からこの語に直します。

0.8.0 で、英語を和語に言い換えた、一般には使わない言い回しを見直すために作り、語ごとに利用者が承りました (96 語。後から利用者の指摘で足した語は、一覧の補足に書く)。
ソフトウェアの文書で普通に使う IT の用語 (カタカナ語を含む) と、組版の用語 (JIS X 4051・JLREQ・CSS・XSL-FO の日本語訳で使う語) を選んでいます。

## 使い方

- 「今の語」の言い回しを新しく書かない。左の語を見つけたら、右の語に直す。
- 「使う語」に複数の語があるものは、補足の文脈で 1 か所ずつ選ぶ (機械的に置き換えない)。
- 熟語の一部・コードの名前・引用・書名・試験の文字列は直さない (例: 「教科書体」「英語版」「版面」「字間」「頭文字」、『CSSページ組版入門』第 4 版)。
- 数え方の「字」(1 字・n 字) は「文字」にしない。
- 「組む」「組版」「字形」は組版の用語として残す。マージンの「相殺」も残す。
- ここに無い語も、同じ考え方 (一般に使う IT・組版の用語を選ぶ) で選び、迷ったら一覧に足す。
